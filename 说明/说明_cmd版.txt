cmd版  说明
================================================
这里放的是 cmd / PowerShell 写的工具，都是备用版本。
新工具以后都用 Python 写，放在上一级目录。


一、提取文件（提取文件.bat + 提取文件_v1.0.ps1）
------------------------------------------------
作用：把子文件夹里的文件全部提到当前目录，只保留文件名。
      下载目录常常套很多层（(1) xxx\ (2) xxx\），跑一次就提到一层。
运行：双击「提取文件.bat」，处理的是 bat 所在目录；
      也可以把别的文件夹拖到 bat 上。

发现重名会停下来让你选：
      1 = 所有文件加序号前缀        001_原文件名.ext
      2 = 所有文件加来源文件夹前缀  顶层文件夹名_原文件名.ext
      3 = 跳过重名文件              保持原样，最后列在报告里
      0 = 取消
之后还会问「要不要删除变空的子文件夹」，默认不删。
跑完生成「提取记录.txt」，里面记了方案、统计、以及跳过的那批文件。
绝对不会覆盖已有文件（撞车会自动加 (2)）。


二、音量处理（处理视频音量_v1.4.bat + 音量处理_v1.4.ps1）
------------------------------------------------
这是音量处理的 PowerShell 老版本（v1.4），功能和新版 Python（v1.5）一样，
默认档是 4 很强（新版默认 5 最强）。留着当备用，平时用上一级目录的 Python 版就行。

用法：把这俩文件放进放视频的文件夹，双击 bat；或把文件夹拖到 bat 上。
档位：1 温和 / 2 明显 / 3 强力 / 4 很强（默认）/ 5 最强 / 9 只检查

命令行参数：
      -Mode 1/2/3/4/5/9   直接指定档位，不询问
      -Overwrite          已有处理结果也重新处理
      -OutDir "D:\输出"   指定输出目录


三、更新 BiliTools（自用版：1.4.6 命名优化版）
------------------------------------------------
用途：把编译好的新版 BiliTools 替换到安装目录。
用法：先完全退出 BiliTools（托盘图标也要退），再右键本文件 → 以管理员身份运行。
说明：新版相对原版的改动——
  1. 文件名变量 {showtitle} 优先使用「视频标题」（原来在合集里会被合集名覆盖）
  2. 新增 sub(起始,结束,{变量}) 取子串，例如 sub(7,15,{showtitle}) -> 2026/9/14
  3. aria2 加 --file-allocation=none，并把本地接口超时 3 秒放宽到 60 秒
     （修掉大文件下载时任务被误判失败、临时目录被清导致死循环的问题）
原版 exe 备份在：C:\Program Files\InternetApp\CodexApps\BiliTools-构建\_原版备份\

【自用版文件位置】
  安装包（可拷到别的电脑安装）：C:\Program Files\InternetApp\CodexApps\BiliTools_1.4.6_命名优化版_x64-setup.exe
  独立 exe（绿色版）：        C:\Program Files\InternetApp\CodexApps\BiliTools_1.4.6_命名优化版.exe
  软件里怎么看版本：打开「关于」页，显示 v1.4.6 命名优化版

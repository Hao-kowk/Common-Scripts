# 我的脚本合集

自己用的 Windows 小工具，主要是给 B 站录播做音量压缩、批量转字幕、文件批量改名这些事。
用 Git 同步到 GitHub：<https://github.com/Hao-kowk/Common-Scripts>

根目录只放正在用的 `.py` 脚本，其他东西都在 `其他\` 里。

---

## 一、脚本清单

| 脚本 | 干什么的 | 怎么用 |
| --- | --- | --- |
| **音量处理** | 把视频里突然变大的音量压下去，其他部分尽量不动。画面原样复制、不重编码，**画质无损** | 放到视频所在文件夹双击。会先让你选强度：`1 温和 / 2 明显 / 3 强力 / 4 很强 / 5 最强`（直接回车就是 5），输入 `9` 只检查不处理。成品在 `_处理后\`，附一份「处理报告.txt」 |
| **批量转字幕** | 视频转字幕。网上那些语音转文字工具大多有时长限制，Whisper 又慢又不准，所以这个是**专为长视频写的，6 小时以上的录播也能转**。用的是 B 站接口（必剪 Bcut 的 AI 转写），**目前只测试过中文和英文语音** | 双击（处理脚本所在文件夹），也可以把文件夹或文件拖到脚本上。需要联网，不需要账号，中途断了重跑会接着来 |
| **字幕加后缀** | 给 `.srt` 的名字加 `_音量压缩`，并复制一份进 `_处理后\`，让播放器自动加载字幕 | 双击，先出预览，回车确认；输入 `0` 取消 |
| **按标题日期改名** | 读文件名里的 BV 号，去 B 站查真实标题，把日期提到名字最前面 | 双击，先预览再回车 |
| **修复bilitools记录** | 修 BiliTools 的 `Cannot read properties of undefined (reading 'id')` 报错；动手前自动备份数据 | 先**完全退出** BiliTools（托盘图标也要退），再双击 |
| **获取所有子文件夹** | 读 `文件夹列表.txt`，筛选后输出 `filtered_dirs.txt` | 旧脚本，用得少 |
| **批量翻译字幕** | 字幕翻译。内置腾讯、有道、Google 三个免费接口，**都不用申请 Key**，其中腾讯和有道国内直连、不用梯子 | 双击（处理脚本所在文件夹），也可以把文件夹或文件拖到脚本上。默认走腾讯，翻完出 `xxx.zh.srt`（纯译文）和 `xxx.zh.bilingual.srt`（中英对照）。中途断了重跑会接着来 |
| **YouTube下载** | 下载 YouTube 视频。**先整段下、再本地切**——只下某一段反而更慢（分段下载只能单连接），所以哪怕你只要最后 3 小时，也是整段下完再切。不重编码、画质无损，支持断点续传 | 双击，粘链接回车，再按提示决定要不要只留一段（直接回车=整段，输 `3`=只要最后 3 小时）。成品在 `_下载\`。换画质加 `--quality 720`，切完想删中间文件加 `--cleanup` |

上面每行对应根目录里的一个 `.py` 文件，文件名自带版本号，比如 `音量处理_v1.5.py`。

## 二、新电脑第一件事：装 Python（一键安装，很简单）

脚本都是 Python 写的，一台电脑只需要装一次，全程不用改任何设置。

1. 打开 <https://www.python.org/downloads/>，点那个黄色按钮 `Download Python 3.x.x` 下载，然后双击安装包（3.12 或更新的都行）。
2. 第一屏点 `Customize installation`（自定义安装）。
3. 接着会出现两个勾选页面，只要确认这两项是勾上的，其他全部默认就行：

   - `pip`
   - `Add Python to environment variables` ← 就是下面这张图

   ![Python 安装时勾选 Add Python to environment variables](其他/Python安装-勾选环境变量.webp)

4. 点 `Install`，等进度条走完，最后一页点 `Close`，就装完了。
5. 验证：按 `Win + R`，输入 `cmd` 回车，再输入 `python --version` 回车。

   - 显示 `Python 3.x.x` → 装好了。
   - 提示"不是内部或外部命令" → 环境变量那个勾没打上，重新双击安装包选 `Modify` 补勾即可。

> 嫌麻烦也可以第一屏直接点 `Install Now`，但**底部那个 `Add python.exe to PATH` 必须勾上**。

## 三、另外还需要一个 ffmpeg

**操作音视频文件的需要安装该程序。** 「音量处理」和「批量转字幕」都要用到它，只跑改名类的脚本可以不装。

脚本会按下面顺序自己找，找到哪个用哪个：

1. 脚本旁边的 `ffmpeg\bin\ffmpeg.exe`（把整个 ffmpeg 文件夹丢在脚本旁边最省事）
2. 系统环境变量 `PATH` 里的 ffmpeg（推荐，一劳永逸）
3. 两条写死的路径：`C:\ffmpeg\bin\` 和 `C:\Users\Halpc_TUF\Documents\Codex\ffmpeg\...\bin\`

都没有的话，脚本会直接提示「找不到 ffmpeg / ffprobe，无法处理」。

## 四、文件夹结构

| 位置 | 放什么 |
| --- | --- |
| 根目录 | 正在用的 `.py` 脚本 + 这个说明 |
| `其他\cmd版\` | `.bat` / `.ps1`，双击就能跑的入口 |
| `其他\说明\` | 每个脚本的详细说明 |
| `其他\老版脚本\` | 旧版本脚本、以前的 bat，以及不用了的脚本 |
| `其他\老版脚本\更新日志\` | 一个脚本一个 `.txt`，记录每一版改了什么 |
| `其他\优化软件\` | BiliTools 4.63 命名优化版（exe 和安装包，换版本用里面的「更新BiliTools.bat」） |
| `其他\软件配置导出\` | 软件设置导出的 `.reg` |

## 五、改脚本的规矩

- 文件名带版本号，例如 `音量处理_v1.5.py`，一眼能看出哪个是新版。
- 出新版**不覆盖**旧版：新的放根目录，旧的移到 `其他\老版脚本\`。
- 每改一版，在 `其他\老版脚本\更新日志\` 对应那个 `.txt` 里补一条改动记录。

## 六、改动怎么同步到 GitHub

改完文件后要「提交 + 推送」才会同步上去——需要的时候跟我说一声，我帮你做。

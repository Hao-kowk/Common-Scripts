# 所有脚本

个人脚本仓库，用来在多台电脑之间同步，并备份到 GitHub。
改脚本时请遵守下面的规矩，避免又出现"不知道哪个是新版"的情况。

## 目录结构

| 位置 | 放什么 |
| --- | --- |
| 根目录 | 只放正在用的 `.py` 脚本（文件名带版本号）+ `README.md` |
| `其他\cmd版\` | `.bat` / `.ps1`，双击就能跑的入口 |
| `其他\说明\` | 每个脚本对应的使用说明 |
| `其他\老版脚本\` | 旧版本脚本、你的旧 bat、更新日志 |
| `其他\老版脚本\更新日志\` | 一个脚本一个 `.txt`，记录每版改了什么 |
| `其他\优化软件\` | BiliTools 命名优化版（exe / 安装包 / 更新脚本） |
| `其他\软件配置导出\` | 软件设置导出（.reg） |

## 正在用的脚本

| 脚本 | 作用 |
| --- | --- |
| `音量处理_v1.5.py` | 把视频里突然变大的音量压下去，画面不重编码 |
| `批量转字幕_v1.2.py` | 用 B站必剪（Bcut）接口批量生成外挂 `.srt` |
| `重命名下载文件_v1.0.py` | 精简 BiliTools 下载的超长文件名 |
| `按标题日期改名_v1.0.py` | 按 B站真实标题里的日期改名 |
| `修复bilitools记录_v1.0.py` | 修复 BiliTools 下载记录报错 |
| `字幕加后缀_v1.0.py` | 给 `.srt` 加后缀并复制到 `_处理后\` |
| `获取所有子文件夹.py` | 列出所有子文件夹 |

## 版本规则

- 文件名带版本号，例如 `音量处理_v1.5.py`。
- 更新脚本**不覆盖**旧文件：旧的移到 `其他\老版脚本\`，新的放根目录。
- 每改一版，在 `其他\老版脚本\更新日志\` 对应 `.txt` 里补一条。

## 编码约定（改文件时别搞乱）

- `.bat`：GBK + CRLF
- `.ps1`：UTF-8 **带 BOM** + CRLF
- `.py` / `.md` / `.txt`：UTF-8

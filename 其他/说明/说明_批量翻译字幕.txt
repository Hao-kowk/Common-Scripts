批量翻译字幕工具（免费接口，不用 API Key）  使用说明
=========================================

作用
----
把 .srt 字幕的文字翻成另一种语言，序号、时间轴、条数原样保留，
在字幕旁边生成译文。不碰视频文件。

一次出两份：
  xxx.zh.srt            纯译文
  xxx.zh.bilingual.srt  中英对照（原文一行、译文一行）


一、最省事的用法
----------------
1. 双击「批量翻译字幕.bat」（在 cmd版 文件夹里）
2. 等它跑完，字幕旁边会出现 .zh.srt 和 .zh.bilingual.srt

默认处理「脚本自己所在的文件夹」里的所有 .srt。
也可以把文件夹、或者单个 .srt 拖到 批量翻译字幕_v1.1.py 上。


二、命令行用法
--------------
  批量翻译字幕_v1.1.py                        处理脚本所在文件夹的所有 .srt
  批量翻译字幕_v1.1.py "D:\字幕"               处理指定文件夹
  批量翻译字幕_v1.1.py a.srt b.srt             处理指定文件
  批量翻译字幕_v1.1.py --to en                 目标语言，默认 zh-CN
  批量翻译字幕_v1.1.py --engine google         换引擎，默认 transmart
  批量翻译字幕_v1.1.py --threads 8             并发线程数，默认 6
  批量翻译字幕_v1.1.py --no-bilingual          只出译文，不出中英对照
  批量翻译字幕_v1.1.py --no-verify             跳过「假成功」检查，跑得快一点
  批量翻译字幕_v1.1.py --overwrite             覆盖已存在的译文


三、三个引擎，都不用申请 Key
----------------------------
  transmart（默认）  腾讯交互翻译。国内直连，不用梯子，一次能传多行
  youdao             有道翻译的 demo 接口。国内直连，不用梯子
  google             Google 免费网页接口。免 Key，但国内要能连上 Google

实测过的其他免费接口（目前都不能用，列出来省得你再试）：
  LibreTranslate 的公共实例   403 / 502，基本都要 Key 了
  微软 Edge 那个免 Key 接口   edge.microsoft.com/translate/auth 已 404 关闭
  MyMemory                   能用，但匿名每天只有 1000 词，翻字幕不够


四、运行环境
------------
需要一个 Python 3（只用标准库，不用装任何第三方包）。


五、注意
--------
1. 时间轴、序号、条数原样保留，只把文本换掉。实测 10280 条字幕零偏移、无空行。
2. 翻译缓存在 %LOCALAPPDATA%\SubtitleTranslate\.translate_cache.json。
   中断后重跑不会重复请求，也不会在脚本目录里多出文件。
3. 本来就已经是中文的句子会原样留着，不会被翻坏。
4. 机器翻译，长句和俚语会有点生硬，人名地名偶尔翻错。
5. 免费接口是第三方服务，偶尔限流，脚本会自动重试，重试不过来会退回逐行翻译。


六、v1.1 修的那个「很多没翻译」
--------------------------------
腾讯这个免费接口会「静默降级」：偶尔把原文原样吐回来，ret_code 还是 succ，
从返回值上看不出任何错。v1.0 没做校验，还把这个假结果写进了缓存，
结果重跑也翻不出来（缓存命中）。

v1.1 起：
  1. 译文和原文一字不差、且原文是英文 → 判定为假成功，逐条单独重试
  2. 重试后确实翻不出来的（单字母、乱码、专有名词）不写进缓存，下次重跑还会再试
  3. 缓存里已有的脏数据会被自动删掉当没命中，不用手动清缓存
  4. 单字母、纯符号直接跳过（省请求）；整批请求失败会逐条救，
     救不回来就保留原文并计数，不会像 v1.0 那样一个批次出错就把整个运行搞崩

实测同一份字幕（2415 条）：没翻的从 202 条降到 14 条。
剩下 14 条是 si / E / w / y / Anywho / Yeah yeah yeah 这类，
要么是单字母，要么是语音识别出来的乱码，接口本身就不给翻。
另外注意：如果视频里本来就有人说中文，那些句子原文就是中文，
翻成中文当然还是原样——这不是没翻。

想跳过这套检查（跑得快一点、但可能漏翻）就加 --no-verify。

视频音量处理工具  v1.5（Python 版）  使用说明
================================================

作用
----
把视频里突然变大的音量段落压下去，其他部分尽量不动。
视频画面原样复制（不重新编码），只重新编码音频，画质零损失。
处理完自动做一次检查，结果写进输出目录的「处理报告.txt」。


一、怎么运行
------------
方式甲（推荐）：把「音量处理.bat」和「音量处理_v1.5.py」一起放到放视频的
文件夹里，双击「音量处理.bat」。

方式乙：把任意视频文件夹拖到「音量处理.bat」图标上，就处理那个文件夹。

方式丙：命令行
    python 音量处理_v1.5.py "D:\某个文件夹"

方式丁：如果 Python 已经注册好（双击 .py 能跑），直接双击
    「音量处理_v1.5.py」也行。


二、运行时会问你什么
--------------------
1. 选择压缩强度（数字越大，大声的部分压得越低）：
      1 = 温和    只压最响的，改动最小
      2 = 明显
      3 = 强力    大声处约压到 -16 dB
      4 = 很强    大声处约压到 -20 dB
      5 = 最强    推荐，直接回车就是它，大声处约压到 -25 dB
      9 = 只检查，不处理
2. 它会列出这次要处理的视频，按回车开始，输入 0 取消。


三、输出
--------
每个视频旁边的「_处理后」文件夹里：
    原文件名_音量压缩.mp4     处理后的视频
    处理报告.txt              每次处理的结果记录

原始文件不会被改动。已经处理过的视频会自动跳过，不会重复处理。
以 _ 开头的文件夹（_处理后、_试听 等）会被自动忽略。


四、检查都查什么
----------------
1. 音频里有没有 NaN / Inf 这类非法采样（正常必须是 0）
2. 输出峰值有没有顶到满刻度（会不会削波）
3. 把整个音轨解码一遍，看有没有解码报错
4. 输出时长和源文件是否一致（差超过 0.5 秒就报警）
5. 视频码率是否和源文件完全一致（确认画面没有被动过）
6. 文件末尾 30 秒是否还有声音（防止音频被截断）
7. 逐秒峰值扫描：找出比整体水平高 30 dB 以上、并且超过 -6 dB 的异常尖峰

所有检查都只是读取、解码、测量，属只读操作，不会修改文件，
也不会凭空产生异常声音。


五、压缩原理（为什么"大声"会变小）
----------------------------------
用的是压缩器：超过阈值的部分才处理，压缩比决定降多少。
实际下降量 = (原音量 − 阈值) × (1 − 1/压缩比)。

各档参数：
    档位   阈值     压缩比   0 dB 的爆音会压到
    1      -13 dB    1:5     -10.4 dB
    2      -16 dB    1:6     -13.3 dB
    3      -18 dB    1:10    -16.2 dB
    4      -22 dB    1:14    -20.4 dB
    5      -26 dB    1:20    -24.7 dB

阈值越低，普通说话被压到的部分也越多，5 档会把整片说话压得比较平。
注意：处理后整体音量会比原片低，播放时把播放器音量开大即可，
小声的部分没有被改变。

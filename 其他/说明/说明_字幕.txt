批量转字幕工具（B站必剪接口 + 外挂字幕）  使用说明
=========================================

作用
----
把这个文件夹（或你指定文件夹）里的视频，逐个用 B 站必剪（Bcut）的语音识别
接口转成文字，在视频旁边生成同名的 .srt 外挂字幕文件。

视频本身不会被修改，也不会重新编码，画质零损失。


一、最省事的用法
----------------
1. 双击「批量转字幕.bat」
2. 等它跑完，视频旁边会出现同名的 .srt 字幕

默认处理的是"这个 bat 所在的文件夹"里的所有视频。
所以想处理某个文件夹，把整个工具文件夹复制过去，或者把视频放进来。


二、命令行用法
--------------
  批量转字幕_v1.2.py "D:\视频\a.mp4"        处理单个文件
  批量转字幕_v1.2.py "D:\视频"              处理整个文件夹
  批量转字幕_v1.2.py --overwrite            覆盖已有的 .srt
  批量转字幕_v1.2.py --chunk 600            每段音频改成 10 分钟（默认 20 分钟）
  批量转字幕_v1.2.py --no-merge             不合并短句，输出原始逐句结果
  批量转字幕_v1.2.py --keep-audio           保留中间文件，方便排查问题


三、接口是什么
--------------
用的是 B 站必剪（Bcut）的语音识别接口，和 AsrTools 里的 Bcut 选项是同一个：

  https://member.bilibili.com/x/bcut/rubick-interface

流程：申请上传 -> 分片上传 -> 提交 -> 创建识别任务 -> 轮询取结果。
不需要账号，不需要 API Key，也不需要登录。


四、运行环境
------------
需要一个 Python 3（只用到标准库，不用装任何第三方包）。
查找顺序：
  1. 本目录\python\python.exe
  2. AsrTools 自带的 C:\Users\Halpc_TUF\Documents\软件\AsrTools-v1.1.0\runtime\python.exe
  3. 系统 PATH 里的 python.exe

想脱离 AsrTools 独立使用，把 AsrTools 的 runtime 文件夹复制成 本目录\python 即可。


五、注意
--------
1. 时间轴是接口返回的真实时间，不是估算的。
2. 处理过程中会在视频旁边生成临时文件（.chunk.mp3 和 .asr_cache.json），
   正常跑完会自动删掉。缓存文件的用处是：中途中断了，重新跑会从断掉的地方继续。
3. 生成的 .srt 是 UTF-8 编码，播放器、剪映、B 站字幕上传都能直接用。
4. 外挂字幕不影响画质。以后要烧进画面再单独做，那一步才会重新编码视频。
5. 接口是第三方服务，偶尔会限流（返回 412），脚本会自动等待重试。
6. 目前只测试过中文和英文语音，其他语言的识别效果还没有验证过。

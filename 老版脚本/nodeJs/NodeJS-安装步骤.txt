Node.js 安装步骤（Windows）
适用：只需要装一个 Node.js，给某个工具（例如 Harness）用。
不需要版本切换器，不需要命令行折腾。


====================
一、下载（2 分钟）
====================

1. 打开浏览器，访问：https://nodejs.org
2. 点页面中间那个大按钮，写着 LTS 的那个。
   要点：选 LTS，不要选 Current。
   按钮上通常写着 "22.x.x LTS"，旁边有小字 "Recommended for most users"。
3. 下载 Windows 安装程序（Windows Installer (.msi)，64-bit）。
   文件名类似 node-v22.14.0-x64.msi，大约 30 MB。


====================
二、安装（3 分钟）
====================

1. 双击刚下载的 .msi 文件。
2. 一路点 Next（下一步），所有选项都用默认值。
3. 关键一步：如果看到这个复选框
      Automatically install the necessary tools
      （自动安装必要工具）
   把它的勾去掉，再点 Next。
   它会让电脑去装 Python 和 C++ 编译工具，要几十分钟，又容易卡住，
   平时完全用不到。这是新手安装失败最常见的原因。
4. 点 Install，等进度条走完，点 Finish。


====================
三、验证（15 秒）
====================

1. 按键盘上的 Win 键，输入 cmd，按回车，会出现一个黑色窗口。
2. 输入下面这行，按回车：

      node -v

   显示类似 v22.14.0，就是成功。
3. 再输入下面这行，按回车：

      npm -v

   显示类似 10.9.2，就是成功。
   （npm 不用单独装，它跟着 Node 一起装好了）
4. 关掉窗口。到此结束。


====================
常见疑问
====================

问：需要管理员权限吗？
答：安装时会弹一个"是否允许此应用更改你的设备"，点"是"就行。

问：需要单独装 npm 吗？
答：不需要。npm 是 Node 自带的一部分，装 Node 就有了。

问：需要装 nvm / fnm 这类版本切换器吗？
答：现在不需要。只有当以后出现"工具 A 要 Node 18、工具 B 要 Node 20"
    这种必须同时存在两个版本的情况，才需要它。到时候再装也不迟。

问：以后 Node 出新版本怎么升级？
答：下载新版 .msi 双击安装即可，它会自动覆盖旧的，不用先卸载。

问：装完之后 npm 能装东西吗？会不会又要配一堆东西？
答：能。Harness 的安装说明里如果写 "npm install -g 某某"，
    在 cmd 里直接粘贴那行命令回车就行。

问：以后用 npm install -g 装了个工具，敲命令却提示"不是内部或外部命令"怎么办？
答：这不是装失败，包已经装好了，只是命令所在的那个目录不在 PATH 里。
    全局命令生成在这个位置：%APPDATA%\npm
    而官方安装程序默认只往 PATH 加了 C:\Program Files\nodejs\ 这一条，
    没有加 %APPDATA%\npm。（这是实测结论，网上很多说法是错的。）

    只补这一条就够了：
      设置 → 系统 → 系统信息 → 高级系统设置 → 环境变量
      → 在"用户变量"里选中 Path → 编辑 → 新建 → 输入 %APPDATA%\npm → 确定
      然后重开一个 cmd 窗口再试。

    注意：不要去动 npm 的 prefix 和 cache 设置，那是另一回事，
    也是那个 B 站视频里引发一堆报错的原因。


====================
如果你同时在看 B 站那个教程
====================

那个视频教的是"全手工配置"的老办法，评论区 197 条里翻车的基本都是它引出来的。
判断规则只有一条：视频里凡是让你手动改设置的地方，一律跳过。

不要做（一条都别做）：
  × 装完去新建 node_global、node_cache 这两个文件夹
  × 改 npm 的 prefix、cache 设置
  × 手工新建环境变量、往 PATH 里加东西
  × 用"终端（管理员）"来运行命令
  × 改 Windows 执行策略（Set-ExecutionPolicy 那串）
  × 给文件夹改安全权限
  × 安装时把路径改到 D 盘 —— 用默认的 C:\Program Files\nodejs
  × 装 pnpm、配镜像源（暂时都用不上）

要保留的：
  √ 从官网下载
  √ 点 LTS 那个大按钮（不要点 Current）
  √ 双击 .msi，一路 Next
  √ "Automatically install the necessary tools" 不勾
  √ 装完用 node -v、npm -v 验证

注意：那个视频开头说"百分之百成功，不会有任何问题"，
同一期里他又说"我不知道为什么你们会报错"。这两句是矛盾的，别被前半句安慰到。


====================
出问题了怎么办（重点看这里）
====================

这就是"不会乱"的关键：无论出什么错，都能靠下面三步回到干净状态，
不会越修越乱。所以放心装。

1. 打开  设置 → 应用 → 已安装的应用，
   搜索 Node.js，点它，选择"卸载"。

2. 用文件管理器检查下面两个位置，如果文件夹还在，整个删掉：

      C:\Program Files\nodejs
      C:\Users\你的用户名\AppData\Roaming\npm

   （AppData 是隐藏文件夹。在文件管理器地址栏直接输入 %AppData%
     再按回车，就能进去。）

3. 回到"一、下载"，重新装一遍。就这么多。


====================
如果 Harness 指定了 Node 版本
====================

如果它的安装说明里写着"需要 Node 20"或者"不支持 Node 22"，
那就在这里找对应版本的 .msi：

      https://nodejs.org/en/download/previous-releases

下载那个版本的 Windows Installer (.msi)，安装方法完全一样。
仍然不需要版本切换器。
